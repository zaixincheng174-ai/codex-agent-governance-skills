# Project Adapter for Agent Governance Skill Pack

This project uses the Agent Governance Skill Pack as its governance baseline.

Consult the pack in this order:

1. `core/AGENTS.override.md`
2. `core/skills/`
3. `skills/agent-governance/SKILL.md`

The `core/` materials are canonical protected sources. Do not rewrite them in this project adapter. Add stricter project-specific rules below this adapter only when needed.

Project-specific instructions may narrow scope, add domain gates, or define local validation commands, but they should not silently disable the governance pack.
